# AiXianSuoFengxi · AI 客户意向（线索）分析

面向**钢铁流通领域上下游 B2B 交易平台**的 AI 客户意向分析方案设计。

服务对象覆盖钢厂、一级代理、钢贸商、仓储加工中心、终端用钢企业（工地项目部、机械制造、钢结构厂等）。

---

## 核心结论

在平台内加入 AI 客户意向分析，**技术可行，但会不会伤害主营业务、让买方不敢进来，完全取决于产品的「披露方向」设计，而不是模型能力。**

| | 侵入式（会毁掉平台） | 赋能式（会成为护城河） |
|---|---|---|
| 商家看到 | 客户身份 + 浏览轨迹 + 意向分 + 手机号 | 结构化需求 + 意向分级 + 建议动作（无身份无轨迹） |
| 买方感知 | 我被盯上了 → 转微信、不登录 | 需求被更快更准响应 → 更愿意用平台 |
| 结局 | 买方流失 → 卖方无客可谈 → 双边崩塌 | 撮合效率提升，绕单减少 |

三条决定成败的关键选择：

1. **披露方向**：个体行为明细永不出平台，商家只拿聚合/分级/建议动作。
2. **数据边界**：跨商家画像不下放到单个商家；IM 分析结果只回本会话。
3. **变现方式**：按成交 / 效果 / SaaS 订阅收费，**绝不按线索条数收费**（否则产品必然滑向侵入式）。

推荐的核心形态是**匿名询价（Blind RFQ）+ AI 需求标准化**：买方匿名发需求，AI 把「四百螺 二五 两百吨 唐山提」翻译成标准询单，多家卖方盲报价，买方选定后才互相揭示身份。买方敢用，卖方拿到高质量真实需求，平台抑制绕单。

## 建议的最小切口

如果只做一件事，就做**在线咨询（IM）意向评分**。它是唯一**不产生新增信息不对称**的形态——对话本来就是商家亲自聊的，他早已全文可见，AI 只是把他已掌握的信息结构化和排序，因此买方几乎不会产生「被监视」的顾忌。

但不要只输出一个孤立的分数（商家会觉得「这我自己不知道吗」），要做成**会话需求卡片 + 意向排序 + 下一步动作**，并给买方对称的 AI 能力（多家报价折算比对、要素缺失提示）。详见文档 06。

---

## 两个最容易被忽略的要点

**行情基线归一**：钢价上行周期全平台浏览与询价同步暴涨。若直接用绝对行为量建模，模型学到的是「今天钢价涨了」而不是「这个客户想买」，全平台意向分一起飘红，销售无法排序，功能直接失效。必须用同期同品类同区域的相对分位，并把行情因子作为控制变量剥离。

**线索保鲜期**：钢贸询价窗口以小时计（早盘调价后集中询价），高意向线索有效期通常不超过 24 小时。隔天推送的「高意向客户」大概率已在别处成交。这决定了链路必须实时，也决定了囤积和导出线索毫无价值。
