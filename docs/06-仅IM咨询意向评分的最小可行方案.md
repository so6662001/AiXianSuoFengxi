# 专项评估：只做「在线咨询意向度评分」是否可行

> 命题：用户在平台内通过在线咨询（IM）联系商家，平台用 AI 对这个客户的咨询行为做**意向度评分**，仅此一项功能，是否可行？

---

## 一、结论

**可行，而且这是整个 AI 意向分析里风险最低、见效最快的切入点。** 但有一个重要修正：**「只输出一个分数」是不够的，甚至会失败。**

理由分两层：

**为什么风险最低——因为它不产生「新增的信息不对称」。**

这是本方案最关键的合规与信任红利，值得单独讲清楚：

- 把「客户的浏览轨迹、收藏、跨商家比价」告诉商家 → **商家原本不知道这些，AI 让他知道了**。这是新增披露，是买方顾忌的真正来源。
- 把「这段咨询会话的意向评分」告诉商家 → **这段对话本来就是商家亲自聊的，他早就全文看过**。AI 只是把他已经掌握的信息做了结构化和排序。

所以在纯 IM 咨询场景里，**买方并没有丧失任何信息优势**——他在聊天里说的每一句话，本来就是主动说给这个商家听的。「被监视」的感觉从根上就弱得多，寒蝉效应的触发条件基本不存在。

**为什么「只给一个分数」会失败——因为分数不是产品，只是排序键。**

- 商家亲自聊过这段对话，你给他一个「87 分」，他的第一反应是**「这我自己不知道吗？」**——分数没有提供任何他不知道的信息，感知价值接近零。
- 分数最没有可解释性。钢贸销售对黑盒极不信任，「87 分」比「他确认了 HRB400E Φ25、200 吨、唐山自提、本周要，还问了质保书和账期」弱一个数量级。
- 分数的真正价值在**跨会话排序**：一个销售同时挂着 20 个会话，AI 告诉他先回哪一个。这个价值只有在会话量足够大时才显现。

**所以最小可行形态应该是：会话列表按意向排序（分数在后台当排序键）+ 每个会话一张「需求卡片」。** 需求卡片才是商家每天真正会用的东西，分数只是它的附属排序属性。

## 二、与「全行为画像评分」的风险对比

| 风险项 | 全行为画像评分 | 仅 IM 咨询评分 |
|---|---|---|
| 新增信息不对称 | **高**（商家看到原本不知道的行为） | **无**（对话商家本就全文可见） |
| 买方寒蝉效应 | 高（会导致转微信、不登录） | 低（不改变买方已知的暴露范围） |
| 跨商家数据泄漏 | 高（需专门做域隔离） | **天然隔离**（会话本身就是单商家的） |
| 单独同意的必要性 | 强（第 23 条对外提供） | 弱（不向第三方提供，仅辅助会话对方） |
| 联系方式泄漏 | 高（线索必然想带手机号） | **无**（双方已在会话中，无需提供） |
| 骚扰风险 | 高（需反骚扰配额） | **无**（是买方主动发起的咨询） |
| 数据合规复杂度 | 高（跨域画像、PIA、境外推理） | 中（仍需告知同意 + 境内推理） |
| 冷启动难度 | 高（需成交标签、行情归一） | **低**（规则即可高精度） |
| 覆盖率 | 高（所有访客） | **低**（仅平台内咨询的用户，是主要短板） |

**风险几乎全面下降，只有一项变差：覆盖率。** 这正是需要提前做预期管理的地方（见第六节）。

---

## 三、评分怎么算：规则优先，第一版不需要训练数据

钢贸咨询的意向信号高度确定，规则引擎就能做到高精度，**不需要等积累标签**：

### 3.1 评分构成（建议）

| 维度 | 权重 | 判定依据 |
|---|---|---|
| **交易要素齐备度** | 40 | 牌号材质 / 规格 / 数量 / 交货地与提货方式 / 时间 / 计价结算，六项各占约 7 分。要素从 2 项收敛到 5–6 项，就是意向从「看看」变成「要买」 |
| **履约类提问** | 30 | 质保书、材质单、炉批号、过磅还是理计、磅差怎么算、能否开 13% 专票、承兑能否收、账期几天、能否配车卸车、定尺剪切/开平/纵剪等加工。**这类问题只有真要买的人才会问** |
| 互动质量 | 15 | 有效轮次（剔除寒暄）、回复及时性、是否发了采购清单图片/Excel、是否主动追问 |
| 咨询连续性 | 10 | 同一牌号规格连续多日回访、上次咨询未成交但本次要素更完整 |
| 时效与承接 | 5 | 需求时间窗紧迫程度、商家是否有匹配库存 |

**扣分项**：只问价不问交货（同行踩价的典型）、要素长期不收敛、账号主体为同区域钢贸商且只批量询价、早盘调价后 10 分钟内批量群发。

### 3.2 硬规则直升 / 直降

- 直升 A 级：六要素齐备 ≥ 5 项 **且** 命中 ≥ 1 条履约类提问
- 直升 A 级：明确说出「下单 / 签合同 / 打款 / 安排车」类动作意图
- 直降：识别为同行踩价或爬虫模式
- 不评级：会话轮次过少、无任何规格信息（避免噪声污染排序）

### 3.3 LLM 的角色只做抽取，不做打分

```
LLM（私有化/VPC 内）：会话文本 + 图片/Excel 清单 + 语音转写
   ↓ 抽取式输出，JSON Schema 校验，字段级置信度
{
  "grade": "HRB400E",  "spec": "Φ25",  "quantity_ton": 200,
  "delivery": {"mode": "self_pickup", "area": "唐山"},
  "need_by": "本周",
  "settlement": {"weighing": "过磅", "tax": "含税", "terms": "月结30天"},
  "processing": null,
  "fulfillment_questions": ["质保书", "账期"],
  "confidence": {"grade": 0.96, "spec": 0.91, "quantity_ton": 0.88}
}
   ↓
规则引擎打分 → 分级 A/B/C → 附判定依据
```

**分数由规则算，不由 LLM 生成。** 原因：可审计、可运营调参、无幻觉、出问题能定位。LLM 只负责把「四百螺 二五 两百吨 唐山提 过磅含税月结」翻译成结构化字段——这才是它不可替代的地方。

要素抽取依赖规格俗称字典（「四百螺」→ HRB400E、「二五」→ Φ25、「乐从」→ 佛山乐从仓、「理计/过磅」计重方式），这是必须先建的基础设施。

### 3.4 时效

咨询意向的保鲜期同样以小时计。建议：A 级会话超过 4 小时未响应触发提醒，超过 24 小时自动降级并标记为「可能已流失」，进入复盘而非跟进队列。

## 四、展示形态：需求卡片 + 排序，而不是一个数字

```
咨询工作台                                    [ 按意向排序 ▾ ]
──────────────────────────────────────────────────────────────
● A  客户 #8821                        3 分钟前  ⏱ 待回复 3min
     HRB400E Φ25 · 200吨 · 唐山自提 · 本周内
     过磅 / 含税 / 月结30天 · 已问：质保书、账期
     ▸ 依据：六要素齐备 5/6，问了质保书与账期
     ▸ 缺失：未确认具体提货日期
     ▸ 你的可匹配库存：唐山XX仓 Φ25 现货 480吨
     [ 一键生成报价单 ]  [ 追问提货日期 ]

○ B  客户 #7104                        22 分钟前
     Q235B 热卷 · 规格待确认 · 数量待确认
     ▸ 依据：品类明确但要素未收敛，未涉及履约问题
     [ 追问规格与吨位 ]

○ C  客户 #6650                        1 小时前
     仅询价，未涉及规格与交货
```

关键设计点：

1. **等级 + 依据同时呈现**，不给精确分数。销售信的是依据，不是数字。
2. **主打「需求卡片」而非评分**。商家聊了 20 个会话，最痛的是「聊完记不清谁要什么规格」和「不知道先回哪个」，卡片和排序正好各解一个。
3. **给出下一步动作**（追问缺失要素、一键报价、匹配库存），让 AI 从「评判客户」变成「替我干活」。
4. **不显示「紧迫度」「价格承受力」「预算上限」**。虽然商家自己读对话也能感觉到客户急，但平台**盖章式地把主观感觉变成一个确定的数字，性质不同**：它会让销售在议价中更强硬，等于平台间接参与了对买方的价格剥削，责任也落在平台身上。这一条必须守住。

## 五、买方侧怎么处理才不引起顾忌

虽然风险远低于行为画像，但仍有两点必须做：

**1. 明示，不静默。** 会话内首次触发 AI 辅助时给出可见提示，并提供关闭入口：

> 💡 AI 助手已帮商家整理了你的需求清单（钢种、规格、吨位、交货方式），这样对方能更快给你准确报价。[了解详情] [关闭]

**2. 双边对称赋能——这是消除顾忌最有效的手段。** 买方同时也应获得 AI 助手：

- 自动整理多家报价对比（含税/不含税、理计/过磅统一折算成可比口径，这是钢贸买方每天手工做的活）
- 提示要素缺失（没确认磅差处理、没确认票种、没确认卸车责任）
- 合同要素与风险点校验
- 提示对方历史履约表现（准时率、磅差投诉率）

**只要 AI 对买方也明显有用，「平台在分析我」就变成「平台在帮我」。** 单边赋能会被立刻感知为偏袒，这在双边平台上是致命的。

## 六、必须提前管理的四个预期

**1. 覆盖率是最大短板。** 钢贸沟通严重依赖微信，平台内 IM 使用率天然偏低，且愿意在平台内聊的人本身就更认平台（样本有偏）。这意味着：

- 评分只能覆盖一部分真实意向，**大量直接下单的、只看不聊的客户完全不在覆盖范围内**
- 不要把它宣传成「全平台客户意向洞察」，实事求是定位为「咨询会话管理助手」
- 反过来，**这个功能本身可以成为把微信沟通拉回平台的抓手**（因为在平台聊能自动出报价单、自动整理需求），这是它的隐性战略价值

**2. 分数的「权威性放大效应」。** 主观感觉变成平台认证的数字后，销售的行为会被放大。用分级（A/B/C）而非精确分、始终附带依据、明确标注「仅供参考，不作为定价依据」，可以部分缓解。

**3. 责任归属。** AI 判为高意向、销售重点投入、结果没成交 → 商家会归因于 AI。需要在产品内建立反馈闭环（准/不准/已成交），并用这个反馈持续调参，同时向商家展示模块整体准确率，把预期锚定在合理区间。

**4. 平台读取会话内容本身需要合规基础。** 即使不向第三方提供，平台作为处理者读取通信内容仍需告知同意，且推理必须**境内私有化或 VPC 内**，不得调用境外/公共大模型 API（既是数据出境问题，也涉及买卖双方的商业秘密）。

## 七、落地条件清单

上线前必须满足：

- [ ] 规格俗称与牌号标准化字典建成（所有抽取的基础）
- [ ] 会话域独立存储、字段级加密、密钥与业务库分离
- [ ] 推理链路网络出口审计，确认无境外调用
- [ ] 评分**不跨会话、不跨商家聚合**，不写入用户全局画像（技术层面确认无该链路）
- [ ] 出站字段扫描：无原始分、无「紧迫度/价格承受力/预算」、无跨店信息
- [ ] 会话内 AI 提示与关闭入口上线
- [ ] 买方侧对称能力（报价对比、要素提示）同批或紧随上线
- [ ] 隐私政策更新，说明 AI 辅助会话的处理目的与范围
- [ ] PIA 完成（涉及自动化决策）
- [ ] 商家协议：明确评分不得作为差别定价依据
- [ ] 线索/评分禁止导出
- [ ] 反馈闭环（准/不准/已成交）与调参机制就绪
- [ ] 灰度：先螺纹/热卷等标准化品类 + 商家白名单

## 八、度量

**主指标**：咨询首响时长（P50/P90）下降、咨询→有效报价率上升、咨询→成交转化率上升、**平台内 IM 使用率上升**（是否成功把微信沟通拉回平台）。

**护栏**：买方会话内 AI 关闭率（上升即为不适信号）、隐私类工单量、评分准确率反馈（低于阈值就提高阈值，宁少勿滥）、同规格同区域报价离散度（监测有没有人拿等级定价）。

**对照**：保留一批商家不开启该模块，长期对比首响时长与成交转化，避免把行情周期效应误判为功能效果。

---

## 九、一句话总结

只做 IM 咨询意向评分是**正确的第一步**——它不产生新增的信息不对称，因此几乎不会让买方不敢进来；但要把它做成**「会话需求卡片 + 意向排序 + 下一步动作」**，而不是一个孤立的分数，同时给买方对称的 AI 能力。这样它是纯粹的效率工具，风险可控，还能顺带把线下微信沟通拉回平台。
