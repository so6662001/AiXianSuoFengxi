# 落地路线与度量体系

> 排序原则：**先做零隐私风险且商家爱用的，再做需要买方授权的**。这样在触碰敏感数据之前，数据管道、指标体系、商家使用习惯和合规底座都已经跑通，风险窗口最小。

---

## 一、分阶段范围（按依赖关系而非时间排序）

### 阶段一：数据底座 + 卖方自家经营诊断（零买方隐私暴露）

**范围**

- 埋点治理：事件 schema 版本化、脱敏入口、时间戳统一、爬虫/同行流量识别
- 规格标准化字典（牌号、规格、仓库、区域的俗称与同义词）—— 后续所有 NLP 的基础设施
- 数仓分层 ODS/DWD/DWS/ADS + 行情基准数据接入（期货主力、区域现货均价、社库厂库）
- 商家店铺经营诊断看板（**仅自家店铺聚合数据**，k-匿名保护）
- **披露网关骨架**（字段白名单、域隔离、审计日志）—— 即使此阶段还没有敏感字段，也要先建立唯一出口
- 合规底座：隐私政策框架、授权数据模型、审计日志、买方隐私中心（先上「关闭个性化」开关）

**依赖**：无外部依赖，纯内部工程。
**风险**：低。可全量上线。
**验证点**：商家日活进入诊断看板的比例、看板对报价行为的实际影响。

### 阶段二：匿名询价（Blind RFQ）+ AI 需求标准化

**这是整个项目的价值核心，也是「买方不敢进来」问题的根本解法。**

**范围**

- 需求录入：自然语言 / 图片 / Excel 采购清单 → 结构化询单（LLM 抽取 + 字典约束 + 置信度 + 缺失要素追问）
- 匿名分发：按品类、区域、库存匹配度、资质、历史响应速度定向分发，**不含买方身份**
- 盲报价：卖方之间互不可见报价（同时规避价格协同风险）
- 买方选择后双向解密身份 → 进入 IM / 下单
- 响应 SLA：首响时长纳入商家评分并影响后续分发权重
- 反骚扰配额：单询单最多分发 N 家（建议 N ≤ 3）、线索 TTL ≤ 24h、禁止导出

**依赖**：阶段一的规格字典与数仓；卖方库存数据质量（需推动商家资源单结构化）。
**风险**：中低（买方主动发布，天然合规）。
**验证点**：询单量、有效报价率、首响时长、成交转化、买方复用率。

### 阶段三：IM Copilot（双边对称赋能）

**范围**

- 会话内自动抽取规格清单 → 一键生成报价单 / 采购单
- 要素缺失提示（未确认计价方式、未确认票种、未确认提货方式）
- 合同要素校验与风险提示（磅差处理、违约条款、账期与付款节点）
- 语音/图片消息转写与识别
- **双边同时可用**，会话内显式提示 + 可关闭

**依赖**：会话域独立存储与私有化推理端点就绪。
**风险**：中（涉及最高敏感数据，但结果不出会话）。
**验证点**：IM 内成交转化、会话时长下降、Copilot 采纳率、平台内 IM 使用率提升（是否成功把微信沟通拉回平台）。

### 阶段四：授权制意向分级（唯一真正涉及行为画像披露的阶段）

**范围**

- 买方隐私中心新增「意向共享」开关（默认关闭）+ 明确对价权益
- 意向计算引擎：规则优先 → GBDT 补充 → 行情基线归一 → 校准 → 排序
- 卖方工作台「今日高意向询单」：分级 + 需求要素摘要 + 建议动作 + 有效期，**无身份、无轨迹**
- 线索质量反馈闭环（准/不准/已成交）
- 买方读取审计自查页面上线

**依赖**：阶段一至三全部就绪；PIA 完成；商家 DPA 条款生效。
**风险**：高，必须灰度 + Holdout + 护栏自动降级。
**验证点**：见下方护栏指标，**任何护栏越界优先回滚,不与业务指标做交换**。

### 阶段五：平台侧智能撮合与供应链协同（不下放到单商家）

**范围**

- 跨仓库/跨商家凑单与替代规格推荐（解决「差 20 吨凑不齐一车」「非标定尺凑不齐」）
- 区域库存调拨建议、余材与滞销品消化建议
- 钢厂产销协同：区域需求热力与品种结构预测，输出到 S&OP
- 供应链金融风控信号（账期资格预审），需独立授权与独立合规评估

**依赖**：前四阶段的数据资产。
**风险**：中（数据仅用于平台侧，但金融类用途需独立合规链路）。

## 二、度量体系

### 2.1 北极星指标

**平台内有效撮合量**（有效询单 → 有效报价 → 成交的完整链路数量），而非「线索产出量」。

> 指标选择本身就是价值观选择。如果把「线索数」设为主指标，团队会自动走向侵入式。

### 2.2 业务指标（期望上升）

| 指标 | 说明 |
|---|---|
| 询单量 / 买方发起询价率 | 买方是否敢用 |
| 有效报价率 | 卖方是否认真承接 |
| 首响时长（P50/P90） | 钢贸成交的第一决定因素 |
| 询单→成交转化率 | 撮合质量 |
| 平台内成交占比 | **绕单抑制效果，B2B 大宗平台的命门** |
| 长尾规格/余材成交额 | AI 匹配的独有增量 |
| 买方 7/30 日留存 | 双边健康度 |
| 商家 SaaS 续费率 | 工具价值是否成立 |

### 2.3 护栏指标（任一越界即降级或回滚）

| 护栏指标 | 含义 | 处置 |
|---|---|---|
| 买方 7 日回访率 | 主指标，绝不允许下降 | 下降超阈值 → 立即回滚 |
| 「勿扰」开启率 | **寒蝉效应的最灵敏探针** | 上升 → 收紧披露口径 |
| 授权撤回率 | 买方后悔程度 | 上升 → 复核对价与话术 |
| 单买方单日被联系次数 P95 | 骚扰强度 | 超限 → 收紧配额、减少分发家数 |
| 同规格同区域报价离散度 | **价格歧视监测** | 异常扩大 → 排查商家是否用等级定价 |
| 隐私类投诉/工单量 | 直接信号 | 任何上升都需人工复盘 |
| 线索精准度（商家反馈准确率） | 防「假高意向」反噬 | 低于阈值 → 提高意向阈值，宁少勿滥 |
| 买方询价后无人报价率 | 空跑体验 | 上升 → 调整分发策略 |

**「宁少勿滥」是本模块的运营铁律**：漏掉一条线索的损失是有限的机会成本；推错一条线索造成的是销售信任流失 + 买方骚扰投诉的双重损害。

### 2.4 实验设计

- **商家侧 Holdout**：长期保留 10%–20% 商家不接入 AI 线索，作为对照组。这是唯一能回答「AI 到底是带来增量，还是在消耗平台既有存量」的方法。
- **买方侧不做隐私相关 A/B**：授权与告知不能拿来做实验，必须对所有人一致。可对「对价权益组合」和「话术呈现」做实验。
- **灰度维度**：品类（先螺纹、热卷这类标准化程度高的）× 区域 × 商家白名单，三重可控。
- **观察期**：钢价有明显周期，评估必须**跨越至少一个完整的涨跌周期**，否则会把行情效应误判为功能效果。这是钢铁行业做 AB 实验最容易得出错误结论的地方。

## 三、常见失败模式与规避

| 失败模式 | 表现 | 规避 |
|---|---|---|
| 全平台意向分一起飘红 | 涨价周期无法排序 | 行情基线归一（文档 02 第三节） |
| 假高意向反噬 | 销售白打电话，弃用 | 规则优先、阈值从严、可解释依据、精准度闭环 |
| 买方寒蝉 | 勿扰率飙升、转微信 | 匿名 RFQ、单向披露、审计对买方开放 |
| 骚扰投诉 | 一天十个电话 | 分发家数上限、联系配额、静默期、线索 TTL |
| 隔天推线索 | 客户早已成交 | 端到端 < 1 分钟，TTL ≤ 24h |
| 张冠李戴 | 把 A 的需求当成 B 的 | 主体归并置信度阈值，不足则不生成个体线索 |
| 商家倒卖线索 | 买方被平台外骚扰 | 禁止导出 + 截图水印溯源 + DPA 违约处置 |
| 商业模式绑架产品 | 披露口径逐季放宽 | 不按线索条数计费 |
| 只用 IM 特征 | 覆盖率低、样本有偏 | 以要素齐备度为主特征，IM 为补充 |
| 用干预后动作做特征 | 线上崩盘 | 特征时间点严格早于线索生成时点 |

## 四、组织与协作

- **隐私评审前置**：任何新增出站字段必须过隐私评审，评审记录归档（这是防止长期滑坡最有效的制度）。
- **销售端规范与考核**：把首响时长、报价有效性、投诉率纳入商家/销售考核，而不是只看联系量。
- **买方沟通主动化**：功能上线时主动向买方说明「我们做了什么、不做什么」，把透明度当成营销点而不是风险点。在钢贸这个圈子小、口碑传播快的行业，主动透明的收益远大于低调上线。
- **法务与外部律师参与 PIA**，并在披露口径每次变更时复核。
